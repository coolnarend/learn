# Python Learning

## Day 1 Activities - Python Basics

Today focused on understanding foundational Python concepts through examples and a mini exercise.

### Topics Practiced

- Variables and formatted output
- Core data types: string, integer, float, boolean, list, dictionary
- Type checking using `type()`
- Taking user input and converting data types (example: `int(input(...))`)
- Conditional statements (`if`, `elif`, `else`)

### Hands-On Exercise

Built a **Personal Profile App** in `main.py` that:

- Accepts user details (name, age, city, profession)
- Prints a formatted profile summary
- Displays a bonus message based on age group

### Key Learning Notes

- f-strings are useful for readable output formatting.
- Input values are strings by default and may need conversion.
- Proper quote/parenthesis closing is important to avoid syntax errors.

- Completed basic syntax and data type practice.
- Completed one interactive console exercise.
- Ready to continue with Day 2 topics (loops and functions).
